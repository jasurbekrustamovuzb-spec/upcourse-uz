# UpCourse Uz — internetga chiqarish

Bu papka — saytning toʻliq loyihasi. Supabase kalitlari allaqachon
`src/App.jsx` ichiga yozib qoʻyilgan, hech narsani oʻzgartirish shart emas.

## 1. GitHub’ga yuklash (kod bilishingiz shart emas)

1. github.com’da bepul hisob oching (agar yoʻq boʻlsa)
2. "New repository" tugmasini bosing, nom bering (masalan `upcourse-uz`), "Create repository"
3. Ochilgan sahifada "uploading an existing file" havolasini bosing
4. Ushbu papkadagi **hamma fayl va papkalarni** shu yerga sudrab tashlang (drag & drop)
5. Pastda "Commit changes" tugmasini bosing

## 2. Vercel orqali joylashtirish (bepul)

1. vercel.com’ga kiring, "Continue with GitHub" orqali roʻyxatdan oʻting
2. "Add New… → Project" tugmasini bosing
3. Roʻyxatdan yangi yaratgan `upcourse-uz` repository’ni tanlang, "Import"
4. Hech narsani oʻzgartirmasdan "Deploy" tugmasini bosing
5. Bir necha daqiqadan soʻng sizga `upcourse-uz.vercel.app` koʻrinishidagi ishlaydigan havola beriladi — sayt allaqachon internetda!

## 3. .uz domeningizni ulash

1. Vercel’dagi loyihangizga kiring → "Settings" → "Domains"
2. Sotib olgan `.uz` domeningizni kiriting
3. Vercel sizga 1-2 ta DNS yozuvi (odatda A record yoki CNAME) beradi
4. Shu yozuvlarni domeningizni sotib olgan joyning (registrar) "DNS Management" boʻlimiga kiritasiz
5. Odatda bir necha soatdan bir kungacha vaqt ketadi, keyin sayt oʻz domeningizda ishlay boshlaydi

Har bir qadamda savolingiz boʻlsa, Claude’ga screenshot bilan murojaat qiling —
birga davom ettiramiz.
